# CV Website

Kişisel CV / portföy web sitem.  
Kısa, hızlı ve sade bir tasarımla; hakkımda, yetkinliklerim, projelerim ve iletişim bilgilerimi tek sayfada sunar.

## ✨ Özellikler
- Responsive (mobil/desktop uyumlu) arayüz
- Projeler / deneyimler / yetkinlikler bölümleri
- Kolay içerik güncelleme (dosyaları düzenleyerek)
- Hızlı deploy (GitHub Pages / Vercel / Netlify ile)

## 📁 Proje Yapısı
> Dosya isimleri sende farklıysa bu bölümü güncelleyebilirsin.

- `index.html` – Ana sayfa
- `assets/` – Görseller, ikonlar, fontlar
- `css/` veya `styles/` – Stil dosyaları
- `js/` – Script dosyaları (varsa)

## 🚀 Çalıştırma
Bu proje statik bir web sitesidir.

### Yerelde açma
- `index.html` dosyasını tarayıcıda açabilirsin  
**veya**
- VS Code + Live Server eklentisi ile çalıştırabilirsin.

## 🌍 Yayınlama (GitHub Pages)
1. GitHub repo → **Settings** → **Pages**
2. **Build and deployment** bölümünde:
   - Source: **Deploy from a branch**
   - Branch: **main** / (root)
3. Kaydettiğinde birkaç dakika içinde site yayına alınır.
